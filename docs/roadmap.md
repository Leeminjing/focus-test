# 实施路线

当前已经可以封存目录，通过统一调度执行 Node/pytest，并查询持久化事件和结果。以下复选框只表示已实现及验证的部分；完整目标见 [design.md](design.md)。

## M0 输入封存与协议

- [x] 版本化真实执行请求，区分 Request、Job 和 Attempt。
- [x] 含未提交及 Git 忽略文件的 manifest、SHA-256 内容存储。
- [x] 两轮复制核验、变化拒绝、链接与越界拒绝、独立物化目录。
- [x] 环境和策略身份、规范化执行键；调用方不进入执行键。
- [x] 协议校验、幂等冲突、范围及版本边界，CLI 和 HTTP 链路。
- [x] 执行后复核声明输入，修改原始输入不能产生通过。

`verified_copy` 是实际复制字节的身份；原子工作区版本仍需 Focus 写屏障。环境依赖清单只描述已知输入，不能凭 lockfile 宣称运行器安装包已封存。

## M1 集中运行

- [x] 请求订阅与实际执行分离。
- [x] 完全相同模拟请求的在途合并及原始 Attempt 归属。
- [x] 明确选择 node-sealed-v1 的真实在途共享、独立取消与不同脏快照分离。
- [x] CPU/内存准入、同 Context FIFO、跨 Context 轮转、独占资源、老任务预留。
- [x] 取消和等待期限只影响当前订阅，最后一个订阅离开才取消 Job。
- [x] 带序号和校验的追加事件日志、同步落盘及终态恢复。
- [x] PR1：事件数量/编码字节双重分页、精确 next_seq、has_more、流尾 terminal；数千事件完整续读。
- [x] 新请求不复用已完成结果，幂等重试保留原请求身份。

通用 node-v1/pytest-v1 仍只允许 `reuse_policy: none`。node-sealed-v1 只开放自包含 CJS/ESM/JSON 单元测试及有限内置模块，完整边界见 [node-sealed.md](node-sealed.md)，不扩展到 npm、数据库或网络测试。

## M2 生命周期可靠性

- [x] Windows 在测试代码恢复执行前绑定 Job Object，取消和超时清理整个 Job。
- [x] POSIX 进程组实现，Linux 后代收养与回收；本机尚未实跑这些平台。
- [x] 启动意图先落盘、单实例 OS 锁、重启不重放未结算任务。
- [x] 未确认真实清理时保留 unknown 并隔离新调度。
- [x] 带校验证据、记录和日志观测配额、分页读取；慢客户端不阻塞日志生产。
- [x] 挂起、子进程、取消、报告损坏/截断、输出洪泛及证据配额测试。
- [x] PR3：引用保护、终态保留期/压力回收、原子日志压缩、快照对象/工作目录清理与容量恢复。
- [ ] 真实磁盘满、同步失败、Windows 服务崩溃场景的故障注入。
- [x] a31de37 的 Linux/macOS CI 通过，Linux 包含 race detector；Windows 的期限测试曾失败。
- [x] 期限回归使用 testing/synctest；两个订阅持久化后才推进期限，消除 20ms 真实调度竞争。

## M3 真实测试适配

- [x] Node 24 内置测试 reporter，准确显式文件范围、早失败和闭合报告。
- [x] 并行“慢文件在前、快失败在后”屏障回归，test:complete 早通知及重复事件关联。
- [x] pytest 收集、setup、call、teardown 与 session 结算。
- [x] teardown/setup 失败、收集错误、零用例不能误判通过。
- [x] 真实进程的输入绑定、清理确认、原工作区不被修改。
- [x] 本地凭据保护执行接口，拒绝未实现的沙箱策略及额外运行参数。

pytest 当前单进程，通用 Node 按声明 workers 执行。受限 Node 固定一个进程并验证自己的模块边界；通用安装依赖闭包、完成结果缓存均未开放。

本仓库尚未部署进 Focus，`focus-broker` 会拒绝执行。可选图验证使用真实 Focus 安全上下文、图准备及 typed history，但模型是本地脚本，图 checkpoint 在内存；运行时及反馈日志真实落盘。这不能替代生产 Patrol 接入，也不能让本地结果直接满足 Focus 完成验收。

## 当前增量顺序

PR1 事件分页、PR2 耐久消费、PR3 保留容量分别开发为可审查提交。
PR4 的 Provider/身份协议及 Focus 本体受治理执行、唤醒与采纳仍待实现。
PR5 的不同脏工作区、部分重叠/不重叠、真实项目 Node/pytest、CPU/RSS 和完整投递延迟基准仍待实现；现有完全重复负载实验不替代它。

模拟数据与真实自包含测试数据分开保存。真实 Node 负载包含定时器，不代表生产应用性能；真实图反馈验证也不等于生产 Focus 已加速。
